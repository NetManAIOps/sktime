# 检测器参考

先用 `ls algorithms --name` 查参数和管线建议，再打开当前检测器的参考页。
各页的起点来自实现和已知参考配置。预处理来源与旧配置见 [官方参考配置](../official-configs.md)。

RSI 更新某个检测器的实验记录时，写明数据条件、实际参数或管线变化、比较基线、验证指标和可追溯的运行标识。
有多次一致的结果时再更新调参建议。单次观察留在对应模型的实验记录里。
